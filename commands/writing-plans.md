Создай детальный план реализации для: $ARGUMENTS

Начни с заголовка:
```
# [Feature] Implementation Plan
**Цель:** [одно предложение]
**Архитектура:** [2–3 предложения]
**Стек:** [ключевые технологии]
```

Для каждого шага плана обязательно укажи:
- Точные пути к файлам которые нужно создать или изменить
- Полный код (не заглушки и не "реализуй похожим образом")
- Конкретную команду для проверки что шаг выполнен
- Критерий завершения

Запрещено использовать: TBD, TODO, "implement later", "appropriate error handling", "similar to Task N", "и так далее".

Перед финальной версией плана проверь:
- [ ] Все шаги покрывают согласованный дизайн полностью
- [ ] Нет ни одного плейсхолдера
- [ ] Типы данных согласованы между шагами
- [ ] Порядок шагов учитывает зависимости
