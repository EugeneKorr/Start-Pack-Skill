Прими передачу дел от предыдущей сессии и введи себя в контекст: $ARGUMENTS

Ты выполняешь /handoff-query — первый запуск новой сессии после /handoff-ingest.

Рубильник: прежняя версия — файл `~/.claude/commands/handoff-query.md.bak.*`, который оставляет `install.sh`, или история Start-Pack-Skill в git.
Транскрипт ТЕКУЩЕЙ сессии — по `$CLAUDE_CODE_SESSION_ID`, никогда не «самый свежий .jsonl» (в папке работают несколько сессий): `f=$(python3 ~/.claude/tools/handoff/measure.py stats | tail -1 | jq -r .transcript)`.

## Шаг 1. Прочитай записку

1. `docs/HANDOFF.md` — главный источник.
   - «Статус: ПРИНЯТА <дата>» — записку уже забрала другая сессия. Скажи об этом, покажи `git log --oneline -5 -- docs/HANDOFF.md` и спроси, поднять ли нужную версию из истории.
   - Файла нет — скажи прямо, предложи собрать контекст из git log + TODO + wiki; состояние не выдумывай.
2. `docs/TODO.md` — открытые задачи.
3. `git log --oneline -15` и `git status --short --branch`.
4. CLAUDE.md проекта подхватывается автоматически.

## Шаг 2. Проверь вики старой сессии (сам вики НЕ делаешь)

Раздел «Вики и замер» в HANDOFF:
- «вики: сохранена и проверена» — ничего не делай.
- «есть пропуски: …» или пометки нет вовсе (записка старого формата) — ГРОМКО предупреди пользователя в докладе: какие знания могли не попасть в вики и путь к транскрипту старой сессии. Ingest не запускай без его команды.

## Шаг 2а. Название этого чата

Приоритет — из $ARGUMENTS (1/2/3 → 1️⃣ 2️⃣ 3️⃣); нет — спроси одним вопросом «Приоритет 1/2/3?».
Название: «<эмодзи> <Название чата (база) из HANDOFF>» (нет базы — короткое имя проекта).
`printf '{"type":"custom-title","customTitle":"%s","sessionId":"%s"}\n' "<название>" "$CLAUDE_CODE_SESSION_ID" >> "$f"`.

## Шаг 2б. Подтяни вики по теме записки

Шаг 2 проверял, СОХРАНИЛА ли старая сессия свои знания. Этот шаг — другое: ВСПОМНИТЬ, что уже лежит в вики по теме (грабли и решения прошлых сессий, в том числе давних), до начала работы.
Если в проекте есть `wiki/` — выполни /wiki-query по теме и следующему шагу из HANDOFF (одна формулировка, 3–6 ключевых слов). Нужны находки, а не пересказ вики. Нет `wiki/` или ничего релевантного — пропусти и отметь это в докладе.

## Шаг 3. Погаси записку

- «Статус: НЕ ПРИНЯТА» → «Статус: ПРИНЯТА <дата время>».
- Строку «стартовый контекст новой сессии» заполни фактом: `python3 ~/.claude/tools/handoff/measure.py stats | tail -1 | jq .first_ctx` (в тыс. токенов).
- Коммит: `docs(handoff): передача принята`.

## Шаг 4. Доложи и жди задачу

Сжато (5–8 строк):
- состояние одним абзацем;
- что в работе и ТОЧНЫЙ следующий шаг;
- открытые вопросы, требующие решения;
- вики: «сохранена и проверена старой сессией (N тем)» или предупреждение из Шага 2;
- что нашлось в вики по теме (1–3 пункта со ссылками на страницы) или «по теме ничего»;
- экономия: «старая сессия ~X тыс. на вопрос → эта стартовала с ~Y тыс.».

НЕ начинай следующий шаг из HANDOFF без явной команды пользователя.
