Прими передачу дел от предыдущей сессии и введи себя в контекст: $ARGUMENTS

Ты выполняешь /handoff-query — первый запуск новой сессии после /handoff-ingest.

## Шаг 1. Прочитай записку

1. `docs/HANDOFF.md` — главный источник: тема, состояние, следующий шаг, грабли.
   - Если в шапке «Статус: ПРИНЯТА <дата>» — эту записку уже забрала другая сессия. Скажи об этом пользователю, покажи `git log --oneline -5 -- docs/HANDOFF.md` и спроси, поднять ли нужную версию из истории (возможно, он продолжает другой тематический чат).
   - Если файла нет — скажи прямо, предложи собрать контекст из git log + TODO + wiki и продолжай без него (не выдумывай состояние).
2. `docs/TODO.md` — открытые задачи.
3. `git log --oneline -15` и `git status --short --branch` — что реально в репо.
4. CLAUDE.md проекта подхватывается автоматически — перечитывать не надо.

## Шаг 2. Wiki-ingest старой сессии (если помечен как невыполненный)

В HANDOFF, раздел «Транскрипт завершённой сессии»: если «wiki-ingest: выполнен» — НЕ повторяй. Если «НЕ выполнен» — сверься с `wiki/log.jsonl`: есть запись по этому транскрипту → считай выполненным и поправь пометку. Иначе, если путь к .jsonl существует:
- файл < 2 МБ — сразу выполни /wiki-ingest <путь> --local;
- ≥ 2 МБ — предупреди о размере и спроси пользователя, делать ли сейчас.

## Шаг 2а. Переименуй этот новый чат

Приоритет задачи — из аргумента ($ARGUMENTS: 1, 2 или 3 → 1️⃣ 2️⃣ 3️⃣). Если аргумента нет — задай пользователю ОДИН короткий вопрос: «Приоритет 1/2/3?».
Название: «<эмодзи приоритета> <Название чата (база) из HANDOFF>». Пример: «1️⃣ parcel_delivery1». Если базы в HANDOFF нет — возьми короткое имя проекта.
Запиши в транскрипт ТЕКУЩЕЙ сессии: `f=$(ls -t ~/.claude/projects/$(pwd | sed 's/[/_]/-/g')/*.jsonl | head -1)`; sessionId = имя файла без .jsonl; `printf '{"type":"custom-title","customTitle":"%s","sessionId":"%s"}\n' "<название>" "<sessionId>" >> "$f"`. Вкладка может обновиться после переоткрытия чата.

## Шаг 3. Погаси записку

Поменяй в HANDOFF.md: «Статус: НЕ ПРИНЯТА» → «Статус: ПРИНЯТА <дата время>», обнови пометку wiki-ingest (если делал), закоммить одной строкой: `docs(handoff): передача принята`.

## Шаг 4. Доложи и жди задачу

Сжатое резюме (5–8 строк, без пересказа всего HANDOFF):
- текущее состояние одним абзацем;
- что в работе и ТОЧНЫЙ следующий шаг;
- открытые вопросы, если требуют решения пользователя;
- что сделал с вики (ingest выполнен / отложен / не требовался).

Затем жди задачу. НЕ начинай следующий шаг из HANDOFF без явной команды пользователя.
