Просканируй текущий репозиторий и создай или обнови файл CLAUDE.md в его корне.

Изучи структуру проекта:
1. Прочитай существующий CLAUDE.md если есть
2. Найди и прочитай: package.json / pyproject.toml / requirements.txt / setup.py / Makefile / docker-compose.yml и аналогичные конфиги
3. Изучи структуру директорий и ключевые файлы (точки входа, основные модули, тесты)
4. Найди как запустить, собрать и протестировать проект

Затем создай или обнови CLAUDE.md со следующими разделами:
- **Build & Run** — команды установки, запуска, тестирования
- **Architecture** — схема компонентов, основные модули, точка входа, поток данных
- **Key Files** — критические файлы и их роль
- **Patterns & Conventions** — важные паттерны, соглашения команды, неочевидные решения
- **Data Layout** — где хранятся данные, конфиги, логи

В конце напомни пользователю:
"CLAUDE.md обновлён. Закоммить изменения (`git add CLAUDE.md && git commit -m 'docs: update CLAUDE.md'`), чтобы браузерные и мобильные сессии тоже получили актуальный контекст."
