Режим экономии токенов для этой сессии: $ARGUMENTS

Ты выполняешь /economy: пользователь подходит к лимитам подписки или хочет дотянуть текущую нить до естественной паузы дешевле. Задача — за ОДИН вызов инструмента собрать цифры и дать три конкретных рычага. Никаких лишних чтений.

Что определяет цену вопроса: **число обращений к модели × размер контекста × цена модели**. Рычаги ровно три: меньше обращений (`/effort`), меньше контекст (хендофф), дешевле модель (`/model`, агенты).

## Шаг 1. Цифры — один вызов

```bash
M=~/.claude/tools/handoff/measure.py; python3 $M stats | head -2; CLAUDE_CODE_SESSION_ID=$CLAUDE_CODE_SESSION_ID python3 $M gauge | jq -r '.hookSpecificOutput.additionalContext // "контекст ниже 150 тыс. — счётчик молчит"'
```
Лимиты скрипт берёт с сервера (ключ входа из связки ключей; у коллег — после их входа в Claude Code). Если строка «нет данных — смотри /usage» — попроси пользователя прислать три цифры с экрана `/usage` и дальше считай по ним. Если в $ARGUMENTS уже есть цифры («5ч 70, неделя 25, fable 37») — используй их.

## Шаг 2. Рекомендации (таблица, без воды)

| Рычаг | Что сделать | Почему |
|---|---|---|
| Усилие | `/effort medium` (или `low` для текстов/правок/переписки) | обращений на вопрос ≈ в 1,5–2 раза меньше при том же контексте |
| Модель нити | `/model opus` — если нить про тексты, документы, TODO, переписку, правки; Fable оставить для архитектуры, миграций, сложной отладки | Fable в 2 раза дороже и имеет отдельный недельный лимит |
| Агенты | до конца сессии при каждом вызове `Agent` ставь `model: haiku` для поиска/чтения/черновиков и `sonnet` для кода; Fable/Opus агентам — нет | 30%+ расхода уходит на агентов |
| Хендофф | по строке счётчика: «окупится через N вопросов» — если в нити будет больше N вопросов, `/handoff-ingest` на ближайшей паузе | каждый вопрос при 800 тыс. стоит как ~16 в свежем чате |
| Параллель | второстепенные нити поставить на паузу | все сессии делят одно 5-часовое окно |

Правила выбора по лимитам:
- неделя Fable ≥ 70% → настоятельно `/model opus` для всех рутинных нитей;
- 5ч-окно ≥ 80% → только `/effort low`, никаких агентов на Fable, тяжёлое отложить до сброса (покажи время сброса);
- неделя ≥ 85% → предупреди, сколько дней до сброса, и предложи закрыть лишние нити хендоффом.

## Шаг 3. Применяй то, что в твоей власти

Переключить модель и усилие может только пользователь — дай команды одной строкой для копирования (`/effort medium`, `/model opus`). Своё поведение меняй сразу и до конца сессии: агентам ставь дешёвые модели, отвечай короче, объединяй проверки в один вызов, не перечитывай файлы, которые уже видел. Если контекст сессии сжали (`/compact`), эта инструкция может потеряться — пользователь запускает `/economy` снова.

Доклад — 6–8 строк: цифры лимитов, строка счётчика, три команды для копирования, что ты изменил в своём поведении.
