# Writing Plans

Создаёт детальный план реализации для многошаговых задач.

## Обязательный заголовок плана

```markdown
# [Feature Name] Implementation Plan

**Цель:** [одно предложение]
**Архитектура:** [2–3 предложения]
**Стек:** [ключевые технологии]
```

## Требования к каждому шагу

Каждый шаг плана должен содержать:
- Точные пути к файлам
- Полные блоки кода (не заглушки)
- Конкретные команды для запуска
- Критерий завершения (как понять, что шаг выполнен)

## Запрещено

- Плейсхолдеры: `TBD`, `TODO`, `implement later`, `appropriate error handling`, `similar to Task N`
- Неопределённые ссылки: «сделай как в предыдущем шаге»
- Незавершённые реализации

## Перед передачей плана

- [ ] Все шаги покрывают спецификацию
- [ ] Нет плейсхолдеров
- [ ] Типы данных согласованы между шагами
