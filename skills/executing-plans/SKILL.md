# Executing Plans

## Старт

1. Прочитай план критически — подними вопросы ДО начала работы
2. Создай TodoWrite с задачами из плана

## Выполнение каждого шага

1. Отметь задачу `in_progress`
2. Следуй шагам плана точно — не импровизируй
3. Запусти верификацию из плана
4. Отметь задачу `completed` только при прохождении верификации

## Стоп-условия (немедленно остановись и сообщи пользователю)

- Блокер или зависимость, которой нет
- Тест падает и причина непонятна
- Шаг плана неоднозначен
- Повторный провал верификации (>2 раз)

## Завершение

После всех шагов:
1. Запусти полный тест-сьют проекта
2. Предложи пользователю варианты: merge / PR / keep branch / discard
